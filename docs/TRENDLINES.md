# اندیکاتور Auto Trendlines Pro — ترندلاین خودکار از روی سویینگ پوینت‌ها

فایل: `pine/trendlines_indicator.pine` · Pine Script **v6** · مستقل از SP2L/BTB

این اندیکاتور تمام ترندلاین‌هایی را که می‌توان بین سویینگ پوینت‌ها رسم کرد
می‌سازد، بعد آن‌هایی را که قیمت واقعاً به آن‌ها احترام گذاشته نگه می‌دارد و
بقیه را دور می‌ریزد. سپس خطوط باقی‌مانده را به سمت راست ادامه می‌دهد و شکست و
ریتست آن‌ها را دنبال می‌کند.

## نصب

۱. در تریدینگ‌ویو پایین صفحه **Pine Editor** را باز کنید.
۲. کل محتوای `pine/trendlines_indicator.pine` را پیست کنید.
۳. **Add to chart** بزنید.

## منطق کار (چهار فیلتر کیفیت)

```
سویینگ پوینت‌ها  ──▶  هر جفت پیوت = یک خط کاندید  ──▶  چهار آزمون:
                                                     │
   ① Containment  هیچ کندلی بین دو نقطه اتکا نباید خط را بشکافد
   ② Touch        حداقل N پیوت باید روی خط بنشیند (تلورانس بر حسب ATR)
   ③ Slope        خطوط تقریباً عمودی حذف می‌شوند
   ④ Dedup        خطوط تقریباً یکسان ادغام می‌شوند؛ قوی‌ترین می‌ماند
                                                     │
                                                     ▼
                            رسم + ادامه به راست + رصد شکست و ریتست
```

**سویینگ پوینت**: کندلی که High آن از `Left candles` کندل سمت چپ و
`Right candles` کندل سمت راستش بالاتر باشد (برای سویینگ لو، Low پایین‌تر).
اگر هر دو را روی ۳ بگذارید یعنی همان تعریف کلاسیک «۳ کندل چپ و ۳ کندل راست».

**نکته درباره ریپینت**: پیوت ذاتاً `Right candles` کندل تأخیر دارد (تا وقتی
کندل‌های سمت راست بسته نشده‌اند نمی‌توان گفت پیوت است). تمام رسم‌ها و تشخیص
شکست فقط روی کندل‌های بسته‌شده انجام می‌شود، پس خطوط بعد از رسم جابه‌جا
نمی‌شوند.

## تنظیمات

### ① Swing pivots — سویینگ پوینت‌ها

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| Left candles | 3 | تعداد کندل سمت چپ برای تأیید سویینگ |
| Right candles | 3 | تعداد کندل سمت راست برای تأیید سویینگ |
| Pair each new pivot with the last N pivots | 12 | هر پیوت جدید با چند پیوت قبلی جفت شود (بیشتر = خط بیشتر، اسکریپت سنگین‌تر) |
| Max new lines per pivot | 3 | از بین کاندیدهای قبول‌شده حداکثر چندتا رسم شود (قوی‌ترین‌ها اول) |
| Mark swing points | خاموش | نمایش خود پیوت‌ها با فلش کوچک |

عدد ۳ برای اسکالپ و تایم‌فریم پایین، ۵ تا ۸ برای سویینگ تریدینگ و نگه‌داشتن
فقط ساختارهای بزرگ مناسب است.

### ② Trendline quality — کیفیت خط

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| Resistance / Support lines | هر دو روشن | خطوط از سقف‌ها و/یا از کف‌ها ساخته شوند |
| **Minimum touches** | **2** | ۲ یعنی فقط دو نقطه اتکا. ۳ یعنی حداقل یک پیوت سوم هم باید روی خط بنشیند — خیلی معتبرتر، خیلی کم‌تعدادتر |
| Touch tolerance (× ATR) | 0.25 | یک پیوت تا چه فاصله‌ای از خط «برخورد» حساب شود |
| Allowed pierce depth (× ATR) | 0.15 | کندل تا چه عمقی اجازه دارد از خط رد شود بدون اینکه نقض حساب شود |
| Max piercing candles between anchors | 0 | صفر = سخت‌گیرانه: قیمت بین دو نقطه اتکا حق ندارد از خط عبور کند |
| Min / Max candles between anchors | 5 / 300 | فاصله مجاز بین دو نقطه اتکا |
| Max slope (× ATR per candle) | 0.5 | حذف خطوط تقریباً عمودی (۰ = خاموش) |
| Allowed slope direction | Any | `Classic` = فقط مقاومت نزولی و حمایت صعودی · `Reverse` = ضلع دیگر کانال |
| Duplicate merge distance (× ATR) | 0.35 | دو خط نزدیک‌تر از این مقدار، یکی حساب می‌شوند |
| Skip lines that are already broken when found | روشن | خطی که تا لحظه کشف شدن هم شکسته شده اصلاً رسم نشود |
| ATR length | 14 | مبنای مقیاس‌بندی همه تلورانس‌ها |

تمام تلورانس‌ها بر حسب **ATR** هستند، نه پیپ یا درصد؛ یعنی همان تنظیمات روی
طلا، بیت‌کوین و سهام و روی هر تایم‌فریمی یکسان کار می‌کند.

### ③ Breaks & retests — شکست و ریتست

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| Break confirmed by | Close | شکست با **بسته‌شدن** کندل یا با **شدو** تأیید شود |
| Break buffer (× ATR) | 0.05 | حاشیه اطمینان برای فیلتر شکست‌های فیک |
| Confirmation candles | 1 | چند کندل بسته‌شده پشت‌سرهم باید آن‌طرف خط بمانند |
| Keep broken lines on the chart | روشن | خط شکسته‌شده خاکستری/نقطه‌چین می‌ماند |
| …for this many candles | 40 | بعد از این تعداد کندل پاک می‌شود |
| Flag retests of broken lines | روشن | برگشت قیمت به خط شکسته‌شده با برچسب `RT` علامت می‌خورد |

### ④ Display — نمایش

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| Max lines kept alive | 24 | سقف خطوط زنده روی چارت؛ هنگام پر شدن، اول شکسته‌شده‌ها و بعد ضعیف‌ترین‌ها حذف می‌شوند |
| Extend lines to the right edge | روشن | ادامه خط تا لبه چارت |
| …or extend by N candles | 10 | اگر گزینه بالا خاموش باشد، فقط این تعداد کندل جلوتر کشیده می‌شود |
| Line width follows touch count | روشن | خط با برخورد بیشتر، ضخیم‌تر رسم می‌شود |
| Label lines with their touch count | روشن | برچسب `R ×3` یا `S ×2` سر خط |
| Label breaks and retests | روشن | برچسب `B` روی شکست و `RT` روی ریتست |
| رنگ‌ها | قرمز/سبز/خاکستری | مقاومت / حمایت / شکسته‌شده |

### ⑤ Dashboard — داشبورد

جدولی که تعداد خطوط زنده و **نزدیک‌ترین خطوط به قیمت فعلی** را نشان می‌دهد:
سمت (مقاومت/حمایت)، قیمت خط روی کندل جاری، فاصله بر حسب ATR، تعداد برخورد و
جهت شیب.

## آلارم‌ها

هنگام ساخت Alert روی چارت، اندیکاتور `AutoTL` و یکی از این رویدادها را انتخاب کنید:

| آلارم | زمان فعال شدن |
|---|---|
| `Resistance broken` | شکست خط مقاومت به بالا |
| `Support broken` | شکست خط حمایت به پایین |
| `Any break` | هر شکستی |
| `Trendline test` | قیمت در حال تست یک خط زنده است (بدون شکست) |
| `Break retest` | قیمت به خط شکسته‌شده برگشته (پولبک) |

## نسخه‌های پیشنهادی تنظیمات

| سبک | Left/Right | Min touches | Max pierces | Pair depth |
|---|---|---|---|---|
| اسکالپ M1–M5 | 2 / 2 | 2 | 1 | 8 |
| **پیش‌فرض متعادل** | **3 / 3** | **2** | **0** | **12** |
| فقط خطوط معتبر و کم‌تعداد | 3 / 3 | 3 | 0 | 12 |
| سویینگ H1–D1 | 5 / 5 تا 8 / 8 | 2 | 0 | 16 |

اگر چارت شلوغ شد: اول `Minimum touches` را روی ۳ ببرید، بعد
`Max new lines per pivot` و `Max lines kept alive` را کم کنید.

اگر خط کافی پیدا نشد: `Allowed pierce depth` را زیاد کنید یا
`Max piercing candles between anchors` را روی ۱ بگذارید.

## کارایی

منطق سنگین (آزمون Containment) فقط روی کندل‌هایی اجرا می‌شود که یک پیوت جدید
تأیید شده باشد و با اولین نقض، حلقه شکسته می‌شود. روی ۲۰۰۰ کندل دیتای تست، به
طور میانگین حدود ۴۷ تکرار حلقه به ازای هر کندل — بسیار پایین‌تر از سقف اجرای
تریدینگ‌ویو.

## سلب مسئولیت

ترندلاین ابزار تشخیص ساختار است، نه سیستم معاملاتی. این اندیکاتور سیگنال ورود
نمی‌دهد و صرفاً کار رسم دستی خطوط را خودکار و یکدست می‌کند.
