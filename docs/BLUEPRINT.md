## ۱. ایده مرکزی

SP2L مخفف سه جزء است: **Spike** (حرکت شارپ)، **2-Leg** (دو لگ حرکتی، الگوی AB=CD) و
**Level** (سطح ورود). منطق استراتژی در یک جمله:

> **قدرت ← اصلاح ← ادامه** — قدرت اولیه بازار (اسپایک) را ببین، صبر کن بازار نفس بگیرد
> (پولبک)، و در شروع لگ دوم روی یک سطح مشخص و از پیش تعریف‌شده وارد شو.

بازار وقتی با یک جریان سنگین سفارش حرکت شارپ می‌کند، عدم‌تعادل (Imbalance) بین خریدار و
فروشنده ایجاد می‌شود و روی چارت **ناکارآمدی (Inefficiency)** و معمولاً **گپ قیمتی
(P-Gap / FVG)** باقی می‌ماند. اگر جریان اصلی واقعاً قوی باشد، بعد از یک اصلاح کوتاه،
حرکت دوم (Second Leg) در همان جهت شکل می‌گیرد — و SP2L دقیقاً برای شکار همین لگ دوم
طراحی شده است.

## ۲. اجزای ستاپ

### ۲.۱. اسپایک (Spike)

حرکت ناگهانی و پرقدرت بازار. شرایط یک اسپایک معتبر:

| شرط | قانون | پارامتر پیشنهادی |
|---|---|---|
| تعداد کندل | حداقل N کندل **متوالی هم‌جهت** (صعودی: close > open) | `min_spike_bars = 3` |
| بدنه کندل‌ها | بدنه هر کندل نسبت به کل رنجش بزرگ باشد؛ کندل‌های دوجی فقط با تلورانس محدود پذیرفته می‌شوند | `min_body_ratio = 0.5`، `doji_tolerance = 1`، `max_doji_body_ratio = 0.25` |
| گپ قیمتی (P-Gap) | داخل اسپایک حداقل یک FVG سه‌کندلی وجود داشته باشد (صعودی: `low[i] > high[i-2]`) — نشانه ورود نقدینگی جدی | `require_gap = true` |
| قدرت حرکت | طول کل اسپایک از میانگین نوسان بازار بزرگ‌تر باشد (فیلتر Movement Power) | `power_mult × ATR(14)`، پیش‌فرض `1.5` |

- **نقطه A**: ابتدای اسپایک (کف کندل مبدا در ستاپ خرید / سقف کندل مبدأ در ستاپ فروش).
- **نقطه B**: انتهای اسپایک (سقف آخرین کندل اسپایک در خرید / کف آن در فروش).

### ۲.۲. پولبک / اصلاح (Correction)

بعد از اسپایک، بازار وارد فاز اصلاح می‌شود:

- **شروع اصلاح** (ستاپ خرید): کندلی که کفِ کندل قبلی‌اش را می‌شکند (لمس Low کندل قبل).
  در ستاپ فروش برعکس: لمس High کندل قبل.
- اصلاح نباید کل اسپایک را پس بگیرد؛ اگر قیمت به پشت نقطه A برسد (یا بیش از حد مجاز
  ریتریس کند) **ستاپ باطل** است. پارامتر: `max_retrace = 1.0` (۱۰۰٪ اسپایک).
- اگر تا `max_wait_bars` کندل (پیش‌فرض ۲۰) تریگر ورود نیاید، ستاپ منقضی می‌شود.
- نکته کیفی از آموزش پورصمدی: اصلاحِ دوموجی (دو لگ اصلاحی) اعتبار ستاپ را بالا می‌برد.

### ۲.۳. سطح ورود (Level) و تریگر

- **سطح ورود = اکسترمم آخرین کندل اسپایک**: در ستاپ خرید، شکست سقف (High) آخرین کندل
  اسپایک؛ در ستاپ فروش، شکست کف (Low) آن.
- ورود «نه در هیجان اسپایک و نه وسط اصلاح» — فقط وقتی قیمت بعد از پولبک دوباره این سطح
  را می‌شکند (تأیید ادامه روند = شروع لگ دوم / تکمیل CD در الگوی AB=CD).
- پیاده‌سازی: سفارش Buy-Stop/Sell-Stop روی سطح، یا ورود در لحظه عبور قیمت از سطح.

### ۲.۴. حد ضرر (SL)

- پشت کندل مبدأ اسپایک — یعنی **نقطه A**:
  - خرید: `SL = Low کندل اول اسپایک − buffer`
  - فروش: `SL = High کندل اول اسپایک + buffer`
- منطق: اگر قیمت به پشت اسپایک برگردد، فرض «قدرت جریان اصلی» نقض شده است.

### ۲.۵. حد سود (TP)

- پیش‌فرض: **ریسک‌به‌ریوارد ۱:۱** — `TP = Entry + RR × (Entry − SL)` (خرید).
- مبنای نظری: تکمیل الگوی AB=CD (لگ دوم ≈ هم‌اندازه لگ اول).
- `rr` قابل‌تنظیم است؛ در بازارهای رونددار می‌توان بالاتر گرفت یا خروج پله‌ای گذاشت.

### ۲.۶. ورود دوم (اختیاری — میانگین‌گیری کنترل‌شده)

- در **۵۰٪ فاصله ورود تا حد ضرر** می‌توان پوزیشن دوم اضافه کرد؛ میانگین قیمت ورود بهتر
  می‌شود و مدیریت ریسک منعطف‌تر. پارامتر: `scale_in = false` (پیش‌فرض خاموش).

## ۳. فیلترهای محیطی

| فیلتر | قانون |
|---|---|
| تایم‌فریم | بهترین عملکرد در تایم‌فریم‌های پایین: **M1 و M5** (اسکالپ). قابل اجرا در تایم‌های بالاتر. |
| سشن | سشن‌های پرحجم، مخصوصاً **نیویورک**؛ احتمال موفقیت لگ دوم بالاتر است. پارامتر: `session_start/end` (پیش‌فرض 13:30–20:00 UTC). |
| بازار | بازارهای پرنوسان: **XAUUSD (طلا)**، شاخص‌ها، جفت‌ارزهای اصلی. |

## ۴. ماشین حالت (State Machine)

```
IDLE ──(اسپایک معتبر شناسایی شد)──▶ SPIKE_CONFIRMED
SPIKE_CONFIRMED ──(کندل اصلاحی: لمس Low/High کندل قبل)──▶ PULLBACK
  │  └─(اسپایک ادامه یافت: سطح ورود/B به‌روز می‌شود)
PULLBACK ──(شکست سطح ورود)──▶ IN_TRADE
  │  ├─(قیمت پشت A رفت)──▶ IDLE  (ابطال)
  │  └─(max_wait_bars گذشت)──▶ IDLE  (انقضا)
IN_TRADE ──(برخورد SL یا TP)──▶ IDLE
```

## ۵. شبه‌کد ورود (ستاپ خرید)

```text
برای هر کندل جدید:
  اگر IDLE:
      اگر min_spike_bars کندل متوالی صعودی با بدنه معتبر + P-Gap + قدرت کافی:
          A  = Low اولین کندل اسپایک
          B  = High آخرین کندل اسپایک          # سطح ورود
          state = SPIKE_CONFIRMED
  اگر SPIKE_CONFIRMED:
      اگر کندل جدید هم صعودی و شارپ بود: اسپایک را گسترش بده (B به‌روز شود)
      اگر Low کندل < Low کندل قبل: state = PULLBACK
  اگر PULLBACK:
      اگر قیمت < A (یا ریتریس > max_retrace): ابطال → IDLE
      اگر High کندل > B: ورود خرید
          Entry = B ، SL = A − buffer ، TP = Entry + rr × (Entry − SL)
          state = IN_TRADE
  اگر IN_TRADE:
      اگر Low ≤ SL: خروج با ضرر    (در برخورد هم‌زمان SL و TP در یک کندل: SL مقدم — فرض محافظه‌کارانه)
      اگر High ≥ TP: خروج با سود
```

ستاپ فروش قرینه کامل همین است.

## ۶. پارامترهای پیاده‌سازی (پیش‌فرض‌ها)

```
min_spike_bars      = 3       # حداقل کندل‌های متوالی اسپایک
min_body_ratio      = 0.5     # حداقل نسبت بدنه به رنج کندل اسپایک
doji_tolerance      = 1       # حداکثر تعداد دوجی مجاز داخل اسپایک
max_doji_body_ratio = 0.25    # آستانه دوجی
require_gap         = true    # الزام وجود FVG داخل اسپایک
power_mult          = 1.5     # طول اسپایک ≥ power_mult × ATR
atr_len             = 14
max_retrace         = 1.0     # حداکثر ریتریس پولبک نسبت به طول اسپایک
max_wait_bars       = 20      # مهلت تریگر بعد از اسپایک
rr                  = 1.0     # ریسک به ریوارد
sl_buffer_pct       = 0.0     # بافر SL (درصدی از طول اسپایک)
scale_in            = false   # ورود دوم در ۵۰٪ مسیر ورود تا SL
session_filter      = false   # فیلتر سشن (پیش‌فرض خاموش برای بک‌تست عمومی)
session_utc         = 13:30–20:00
risk_per_trade      = 1%      # ریسک هر معامله از اکوییتی
```

## ۷. نکات مدیریت ریسک (از آموزه‌های پورصمدی)

- ریسک ثابت درصدی در هر معامله (سایز پوزیشن از فاصله Entry تا SL محاسبه می‌شود).
- قبل از حساب واقعی، **چند ماه بک‌تست** روی نماد و تایم‌فریم هدف (طلا، EURUSD و…).
- ادعاهای وین‌ریت بالا (تا ۸۵٪ در برخی منابع) را باید با بک‌تست خودتان راستی‌آزمایی
  کنید؛ با RR=1:1 حتی وین‌ریت ~۵۵٪ هم سودده است، ولی هیچ عددی را بدون آزمون نپذیرید.
