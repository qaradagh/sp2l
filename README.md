# SP2L — پیاده‌سازی استراتژی Spike-2Leg پورصمدی

پیاده‌سازی قابل‌بک‌تست استراتژی پرایس‌اکشن **SP2L** (اسپایک + دو لگ + سطح) از
محمدعلی پورصمدی، به‌همراه سند بلوپرینت کامل قوانین و نسخه Pine Script برای تریدینگ‌ویو.

**📘 قوانین کامل استراتژی:** [docs/BLUEPRINT.md](docs/BLUEPRINT.md)

## منطق در یک نگاه

```
قدرت (اسپایک + گپ قیمتی) ──▶ اصلاح (پولبک) ──▶ ادامه (لگ دوم)
                                                    │
                              ورود: شکست سقف/کف آخرین کندل اسپایک (سطح B)
                              حد ضرر: پشت کندل مبدأ اسپایک (نقطه A)
                              حد سود: ریسک‌به‌ریوارد 1:1 (قابل تنظیم)
```

## ساختار پروژه

```
docs/BLUEPRINT.md        بلوپرینت کامل قوانین (فارسی) + منابع
sp2l/models.py           مدل‌های داده (کندل، کانفیگ، ستاپ، معامله)
sp2l/strategy.py         ماشین حالت استراتژی (تشخیص اسپایک → پولبک → سیگنال)
sp2l/backtest.py         بک‌تستر کندل‌به‌کندل + آمار (وین‌ریت، PF، دراودان و…)
sp2l/data.py             لودر CSV + تولید دیتای مصنوعی برای دمو
sp2l/cli.py              رابط خط فرمان
pine/sp2l_strategy.pine  نسخه Pine v5 برای بک‌تست/مشاهده روی تریدینگ‌ویو
tests/                   تست‌های واحد (pytest)
```

## اجرا

بدون هیچ وابستگی خارجی (فقط پایتون ۳.۹+):

```bash
# دمو روی دیتای مصنوعی
python3 -m sp2l --demo

# روی دیتای واقعی خودتان (CSV با ستون‌های time,open,high,low,close[,volume])
python3 -m sp2l XAUUSD_M5.csv

# با پارامترهای سفارشی
python3 -m sp2l XAUUSD_M5.csv --rr 1.5 --min-spike-bars 4 --session-filter --trades
```

پارامترهای مهم (پیش‌فرض‌ها مطابق بلوپرینت):

| سوییچ | پیش‌فرض | توضیح |
|---|---|---|
| `--min-spike-bars` | 3 | حداقل کندل متوالی اسپایک |
| `--min-body-ratio` | 0.5 | حداقل نسبت بدنه به رنج کندل |
| `--no-gap` | — | حذف الزام گپ قیمتی (P-Gap/FVG) |
| `--power-mult` | 1.5 | فیلتر قدرت حرکت (× ATR؛ صفر = خاموش) |
| `--rr` | 1.0 | ریسک به ریوارد |
| `--max-wait-bars` | 20 | مهلت تریگر بعد از اسپایک |
| `--scale-in` | — | ورود دوم در ۵۰٪ مسیر ورود تا SL |
| `--session-filter` | — | فقط ورود در سشن (پیش‌فرض 13:30–20:00 UTC) |
| `--risk` | 0.01 | ریسک هر معامله (سهم از اکوییتی) |

## تست‌ها

```bash
python3 -m pytest tests/ -q
```

## تریدینگ‌ویو

محتوای `pine/sp2l_strategy.pine` را در Pine Editor تریدینگ‌ویو پیست کنید و
`Add to chart` بزنید. منطق آن آینه پیاده‌سازی پایتون است و همان پارامترها را
در قسمت Settings دارد.

## ⚠️ سلب مسئولیت

- خروجی دموی `--demo` روی **دیتای مصنوعی** است و هیچ معنایی درباره بازار واقعی ندارد؛
  حتماً روی دیتای واقعی نماد و تایم‌فریم خودتان بک‌تست بگیرید.
- این مخزن صرفاً آموزشی/پژوهشی است و توصیه سرمایه‌گذاری نیست. معامله با اهرم
  می‌تواند به از دست رفتن کل سرمایه منجر شود.
