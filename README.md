# SP2L + Pro BTB — پیاده‌سازی استراتژی‌های پورصمدی

پیاده‌سازی قابل‌بک‌تست دو استراتژی پرایس‌اکشن محمدعلی پورصمدی —
**SP2L** (اسپایک + دو لگ + سطح) و **Pro BTB** (بازگشت به سطح شکسته‌شده) —
با موتور تشخیص اسپایک مشترک، حالت بک‌تست ترکیبی و اندیکاتورهای تریدینگ‌ویو.

**📘 بلوپرینت‌ها:** [SP2L](docs/BLUEPRINT.md) · [Pro BTB](docs/BTB_BLUEPRINT.md)

## منطق در یک نگاه

```
                     ┌─ SP2L:  پولبک کم‌عمق ──▶ ورود Stop روی شکست B ─ R:R 1:1
اسپایک + گپ قیمتی ──┤
                     └─ BTB:   پولبک عمیق ──▶ ورود Limit روی ریتست سطح شکسته‌شده L ─ R:R 2:1

حد ضرر هر دو: پشت کندل مبدأ اسپایک (نقطه A)
حالت ترکیبی: هر دو ستاپ هم‌زمان، یک پوزیشن در هر لحظه، اولویت با BTB
```

## اجرا

بدون هیچ وابستگی خارجی (فقط پایتون ۳.۹+):

```bash
# دمو روی دیتای مصنوعی
python3 -m sp2l --demo

# روی دیتای واقعی خودتان (CSV با ستون‌های time,open,high,low,close[,volume])
python3 -m sp2l XAUUSD_M5.csv

# با پارامترهای سفارشی
python3 -m sp2l XAUUSD_M5.csv --rr 1.5 --min-spike-bars 4 --session-filter --trades

# انتخاب ستاپ: هر دو (پیش‌فرض)، فقط SP2L یا فقط BTB
python3 -m sp2l XAUUSD_M5.csv --setup both
python3 -m sp2l XAUUSD_M5.csv --setup sp2l
python3 -m sp2l XAUUSD_M5.csv --setup btb --btb-rr 2.5 --btb-lookback 12
```

در حالت `both` خروجی، آمار را **به تفکیک ستاپ** هم گزارش می‌کند تا ببینید روی
دیتای شما کدام تاکتیک ورود بهتر جواب می‌دهد.

پارامترهای مهم (پیش‌فرض‌ها مطابق بلوپرینت):

| سوییچ | پیش‌فرض | توضیح |
|---|---|---|
| `--min-spike-bars` | 3 | حداقل کندل متوالی اسپایک |
| `--min-body-ratio` | 0.5 | حداقل نسبت بدنه به رنج کندل |
| `--no-gap` | — | حذف الزام گپ قیمتی (P-Gap/FVG) |
| `--power-mult` | 1.5 | فیلتر قدرت حرکت (× ATR؛ صفر = خاموش) |
| `--rr` | 1.0 | ریسک به ریوارد |
| `--max-wait-bars` | 20 | مهلت تریگر بعد از اسپایک |
| `--scale-in` | — | ورود دوم در ۵۰٪ مسیر ورود تا SL |
| `--session-filter` | — | فقط ورود در سشن (پیش‌فرض 13:30–20:00 UTC) |
| `--risk` | 0.01 | ریسک هر معامله (سهم از اکوییتی) |
| `--setup` | both | ستاپ‌های فعال: `both` / `sp2l` / `btb` |
| `--btb-lookback` | 10 | پنجره یافتن سطح شکسته‌شده قبل از اسپایک |
| `--btb-rr` | 2.0 | ریسک به ریوارد ورودهای BTB |
| `--btb-max-wait-bars` | 30 | مهلت ریتست بعد از اسپایک |
| `--partial` | — | فعال‌سازی پارشال: بستن بخشی از پوزیشن در سطح `--partial-rr` (پیش‌فرض 1R) |
| `--partial-pct` | 0.5 | سهم بسته‌شده در پارشال (۰ تا ۱) |
| `--be` | off | ریسک‌فری: `rr` (رسیدن قیمت به `--be-trigger-rr`) یا `after_partial` (بعد از پارشال) |
| `--be-offset-r` | 0.0 | هنگام ریسک‌فری چند R قفل شود (۰ = دقیقاً نقطه ورود) |
| `--daily` | — | گزارش برایند روزانه (تعداد، برد، سود/زیان، مجموع R هر روز) |

مثال — پارشال ۵۰٪ در 1R، ریسک‌فری بعد از پارشال، تارگت نهایی 2R و گزارش روزانه:

```bash
python3 -m sp2l XAUUSD_M5.csv --rr 2 --partial --be after_partial --daily --trades
```

## تریدینگ‌ویو

سه فایل Pine v5 با منطق یکسان (آینه پیاده‌سازی پایتون) موجود است. برای «حالت
ترکیبی» روی چارت، هر دو اندیکاتور SP2L و BTB را هم‌زمان اضافه کنید.

### اندیکاتور SP2L — `pine/sp2l_indicator.pine`

برای مشاهده زنده ستاپ‌ها روی چارت:

1. در تریدینگ‌ویو پایین صفحه **Pine Editor** را باز کنید.
2. محتوای فایل را کامل پیست کنید و **Add to chart** بزنید.
3. برای آلارم: روی چارت **Alert** بسازید و در قسمت Condition اندیکاتور
   `SP2L` و یکی از رویدادهای `SP2L Long` / `SP2L Short` / `SP2L Any signal`
   را انتخاب کنید.

امکانات نسخه ۲ (شبیه‌سازی کامل معامله روی چارت):

- **باکس اسپایک** با برچسب SPIKE + باکس‌های گپ قیمتی (FVG) و خطوط زنده سطح
  ورود (B، نارنجی) و استاپ (A، قرمز نقطه‌چین) تا وقتی ستاپ فعال است
- **سرنوشت هر ستاپ** روی چارت مشخص است: `✖ Cancelled` (ابطال با برگشت قیمت)،
  `✖ Expired` (انقضای مهلت)، `◌ Skipped` (سیگنال وسط معامله باز)،
  `◌ Off-session` (سیگنال خارج از سشن)
- **خطوط معامله زنده**: Entry (رنگ روند)، SL (قرمز؛ بعد از ریسک‌فری **آبی**
  می‌شود و جابه‌جایی استاپ را نشان می‌دهد)، TP1 پارشال (سبز نقطه‌چین) و TP نهایی
  (سبز) — تا لحظه بسته‌شدن معامله همراه قیمت کشیده می‌شوند
- **پارشال و ریسک‌فری** در تنظیمات: سطح و درصد پارشال، حالت ریسک‌فری
  (`Off` / `At RR trigger` / `After partial`) و آفست قفل سود
- **نتیجه هر معامله** با لیبل بر حسب R: مثلاً `TP +1.50R`، `SL -1.00R`،
  `BE +0.50R`
- **داشبورد** (پایین-راست): برایند هر روز (تعداد معامله، تعداد برد، مجموع R)،
  ردیف جمع کل و لیست آخرین معاملات با ساعت، جهت و نتیجه R
- جدول وضعیت (بالا-راست): فاز ستاپ، جهت، سطوح و وضعیت معامله باز با **R لحظه‌ای**
- پنج آلارم: `Long` / `Short` / `Any signal` / `Partial filled` / `Trade closed`

> شبیه‌سازی معامله در اندیکاتور با همان فرض‌های محافظه‌کارانه بک‌تستر پایتون است
> (برخورد هم‌زمان SL و TP در یک کندل = SL؛ پارشال/ریسک‌فری از کندل بعد از ورود).

### اندیکاتور Pro BTB — `pine/btb_indicator.pine`

همان مراحل نصب. سطح شکسته‌شده (L، آبی) و استاپ (A، قرمز) را زنده رسم می‌کند،
در لحظه ریتستِ سطح سیگنال ورود با Entry/SL/TP می‌دهد و آلارم‌های
`BTB Long` / `BTB Short` / `BTB Any signal` دارد. جدول وضعیت حالت
IDLE / AWAIT RETEST را نشان می‌دهد.

### استراتژی SP2L — `pine/sp2l_strategy.pine`

برای بک‌تست در **Strategy Tester** خود تریدینگ‌ویو. هنگام شروع پولبک، سفارش
Stop روی سطح B پارک می‌شود تا مثل بک‌تستر پایتون داخل کندل روی سطح فیل شود؛
با ابطال یا انقضای ستاپ، سفارش لغو می‌شود. حجم بر اساس درصد ریسک از اکوییتی
محاسبه می‌شود (برای نمادهای CFD/اسپات دقیق است؛ برای فیوچرز مقیاس قرارداد را
خودتان تنظیم کنید).

  حتماً روی دیتای واقعی نماد و تایم‌فریم خودتان بک‌تست بگیرید.
- این مخزن صرفاً آموزشی/پژوهشی است و توصیه سرمایه‌گذاری نیست. معامله با اهرم
  می‌تواند به از دست رفتن کل سرمایه منجر شود.
